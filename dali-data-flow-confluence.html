Daily issuer processing

Tokyo, Singapore, Hong Kong and seven additional issuers send flat files in different layouts to Dali (ETL). Dali ingests and normalizes the records, persists every entry in Oracle, then enriches the stored data and publishes it to Power BI for reporting.

Monthly payment processing

Control-M schedules and triggers the monthly process. Dali reads payment data from Oracle, applies ETL to generate monthly payments, splits them into one file per issuer, and sends the files in the required layout to SUMMIT_FRONT. SUMMIT_FRONT forwards the files to SUMMIT_OTC.

SUMMIT_FRONT splits its response files by issuer. It returns Deal ACK files for successful payments and Deal Error files with the reasons records failed. Dali stores both types of response in Oracle, then publishes the monthly payment results to Power BI. Power BI refreshes the dashboards and reports that the Business Team uses.

Liquidity Collection

Each month, Control-M triggers Dali. Dali reads liquidity data from Oracle, applies ETL, and sends the transformed data to Nat1, which Salesforce maintains. Data chunks illustrate the REST API transfer.
